# 星海音乐源接入评估

检查日期：2026-11-11（Asia/Shanghai）。

## 结论

可以改写为 CPlayer5 的服务端渠道适配器；不能把 LX Music 插件文件直接作为网页模块加载。已实测服务器签发令牌、网易云样本解析以及音频首块读取成功。本文保留初次评估结论；后续已完成网易云 / QQ 原生渠道实现，以及网易云浏览器播放验收，详见 [星海接入与配置说明](xinghai-source.md)。发布与线上验收状态见 [v1.8.0 Release](https://github.com/zcgg2001/CPlayer5/releases/tag/v1.8.0)。

检查文件：用户提供的 `xinghai-music-sourcev2.3.18.js`，21,572 字节，SHA-256 `d2f72c5c0dde51fbaa32c9ca5c634a1ae43eafa952abc1e5a83dab4f578487ab`。文件头与 `SCRIPT_VERSION` 均为 **v3.2.18**，更新时间 2026-11-08；文件名版本不一致。

## 认证与请求适配

脚本首先访问 `https://yy.zddyr.top/lx/api/token.php?device_id=…`，从 `data.token` 获取服务器签发的令牌；后续向 `/lx/api/` 请求播放链接时使用 `X-Token`，可选 `X-License`。本地令牌刷新窗口为 4 分钟；注释称服务端有效期 5 分钟，并可能校验 IP。Worker 出口变化是否影响令牌，尚未验证。

实际实现应将卡密和 ChKSz 密钥保留在服务器 Secret，星海令牌/卡密只发送给星海固定域名。原脚本的通用 `httpFetch` 会把这两个头附加到 GD / ChKSz 请求，不能原样复用。当前提供文件的卡密与 ChKSz 密钥均为空。

现有 `sites/music-channels.js` 可承接搜索/解析/歌词/音频接口及 Range 播放，但 `sites/channel-http.js` 的音频域名与扩展名白名单需要根据实际响应调整。应逐跳校验音频目标，保持现有超时、体积上限、取消、服务端限流与健康度监控。脚本的 IP 查询和自动更新通知不属于播放接入必需功能。

建议先验证网易云与 QQ，成功后加入 `js/music-channels.js`、`js/playback-router.js` 及服务端适配器；酷我补齐官方 ID 后加入，酷狗/咪咕/汽水在元数据与播放验证完成后分别开放。

## 2026-11-11 连通性结果

- 静态阅读源文件，没有执行其初始化、IP 查询或更新代码。
- Node fetch 与 curl 使用系统解析访问星海令牌接口均连接失败。
- 本机解析 `yy.zddyr.top` 得到 IPv4 `0.0.0.0`、IPv6 `::`；`/etc/hosts` 未发现该域名条目。作者主站 `https://zddyr.top/` 返回 HTTP 200，仍链接到上述音源域名。
- 独立查询 1.1.1.1 的 A 记录返回了公网地址。使用该次解析结果进行单次诊断请求，仍保留原域名、TLS SNI 和证书校验：令牌接口 HTTP 200 / code 0，`data.token` 正常签发；网易云样本 ID `259138`、128k 解析 HTTP 200 / code 200，返回 `music.126.net` 下的 MP3 地址。未提供卡密或 ChKSz 密钥，使用明确的 CPlayer5 客户端标识。
- 没有修改 DNS、hosts 或网络配置。系统解析路径与公网解析结果不同；需要排查当前环境解析问题，正式适配器不应硬编码本次诊断 IP。
- 同一网易云样本实际返回 HTTP 的 `m801.music.126.net` MP3 地址。将该平台地址升级为 HTTPS 后，Range 请求返回 HTTP 206、`audio/mpeg`、`bytes 0-4095/4302933`，实际读取 4,096 字节，文件头为 `ID3`。本次仅验证标准音质样本；这说明返回的不只是一个未经验证的 URL。
- 未验证高音质、其他平台、浏览器播放、Cloudflare 出口可用性或长期成功率。源代码的“支持平台”声明不代表上述项目已通过实测。
