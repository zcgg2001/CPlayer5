# 歌词升级实施与验收记录

2026-11-09；CPlayer5 v1.5.0 发布前验收。已生成并检查 `dist` 构建；发布状态以 GitHub Release 与 Cloudflare 实际部署记录为准。

## 实施结果

- 接通在线 YRC 等丰富歌词，统一毫秒文档、真实媒体时钟、词进度、翻译/罗马音/和声。无词时间时使用行级显示。
- 20 个现有模式接入列表/舞台宿主，六类背景独立组合，设置预览与实播共用渲染器。每种模式的具体实现与参数见 [效果说明](lyric-effects.md)。
- 完成文件导入、来源切换/刷新、已关联版本内的择优、单曲校正/外观、配置导入导出。已修复音源自动回退时同一网易云歌曲偏好丢失的问题。
- 按追加要求去掉歌词区域玻璃底板与矩形边界，背景边缘渐隐；排除手机端通用按钮样式对歌词的污染。
- 新增底部音乐喷泉，复用真实 FFT；可调强度/开关，桌面 48、手机/省电 24 条水柱，暂停/静音/隐藏时清空，减少动态效果时关闭。
- 保留原有滚动跟随、旧效果与字号偏好；更新 PWA 缓存和前端资源复制。

## 浏览器验证

通过 Playwright CLI 在本机 Chromium、WebKit 中运行，使用隔离上下文和同源接口夹具，Service Worker 在验收上下文内停用。媒体为可 Range 请求的 45 秒静音 PCM，歌词为原创样本，不依赖第三方音乐可用性。

| 检查 | 结果 |
| --- | --- |
| 2.8 秒逐字定位 | 当前词“城市的”，进度 33.33%，两种引擎一致 |
| 20 模式逐个切换 | 当前行定位正确，桌面无通用底板/边框，单个主喷泉实例 |
| 390×844 手机竖屏 | 无页面横向溢出，当前歌词正确，歌词按钮背景透明、边框 0 |
| 减少动态效果 | 所有喷泉隐藏 |
| 手动导入 + 在线刷新 | 手动选择保留，来源标识正确 |
| 校正 + 点句跳转 | 500 ms 校正对应 1 秒歌词跳到 0.5 秒 |
| 切换歌曲/渠道 | 另一首歌校正归零，返回原歌曲恢复校正与手动歌词 |
| TTML | 翻译、和声、嵌套秒偏移、换行通过 |
| 长句 | 20 个舞台模式在 342×480 区域的中英日/emoji/翻译样本无越界；超长段落可滚动 |
| 页面脚本异常 | 全模式与设置流程均无未捕获 JS 异常 |

喷泉另外使用 Web Audio 的确定性噪声缓冲接入**播放器实际的 AnalyserNode**，再以零增益连接输出。FFT 来自真实音频图，测试没有伪造频谱数组，也没有产生可听噪声。Chromium 与 WebKit 均确认桌面/手机绘制、点击穿透、暂停清空、切离歌词隐藏、停止输入后静音清空。截图记录的是测试输入下的画面，不代表真实歌曲的节拍。

## 复跑与截图

保留三段 Playwright CLI `run-code` 回调（不是 `@playwright/test` 测试套件）：

1. `scripts/verify_lyrics_browser.js`：主播放、模式、手机、导入、设置。自动创建媒体夹具，保留其测试上下文供下一步使用。
2. `scripts/verify_lyrics_fountain.js`：在上一步同一会话中验证实际频谱与喷泉。
3. `scripts/verify_lyrics_layout.js`：创建并关闭独立上下文，检查长句和嵌套 TTML。

启动源代码服务（本地验收使用 8788 端口），创建 `output/playwright/` 后，用 Playwright CLI 打开 `http://127.0.0.1:8788/`，依次将回调文件全文作为 `run-code` 参数。Chromium 和 WebKit 分别使用独立会话。脚本访问的歌词/音频请求被本地夹具拦截，不需要输入音乐服务密钥。测试结束可以关闭这些测试会话。

本次本地截图位于忽略目录 `output/playwright/`：

- `folia-fountain-desktop.png`：无框歌词与桌面喷泉。
- `folia-fountain-mobile.png`：手机歌词与喷泉。
- `folia-mode-*.png`：20 个模式的静态画面。

这些是本次运行产物；重新执行脚本会重新生成，不纳入生产资源。浏览器视口检查不等同于真机 Safari/低端手机性能结论。
