# Android 播放器换源：C 方案

1.17.0 预览版在播放器顶部显示实际音源，例如「GD · 网易云」。点按可打开就近菜单，快速切换当前平台的三个渠道；「全部平台与渠道」打开底部面板。封面页和歌词页共用入口。

## 操作与范围

- 点按渠道即尝试切换当前歌曲；当前渠道带勾选标记，音质使用实际返回结果。
- 完整面板提供网易云、QQ 音乐、Apple Music、酷我和酷狗渠道。跨平台先搜索同一录音版本，不直接转用原平台歌曲 ID；无法确认同曲时保留原音源。
- 「后续播放也优先使用」初始不勾选。勾选后在本次切换成功时记住渠道，也可以对已经在播放的渠道设置优先。下次播放优先尝试该渠道，不可用时自动回退。此偏好保存在本机，不更改搜索、发现页的平台筛选；可在完整面板恢复自动选择。
- ChKSz 仅能手动用于当前歌曲，不会成为后续默认或用于预加载。本地、离线音频和 Bilibili 视频显示相应说明。
- 已导入脚本的当前来源会显示其名称；本菜单提供现有内置渠道，脚本仍在设置中管理。显式设置内置渠道为后续优先时，后续播放使用内置路由，恢复自动选择后回到原先的脚本优先流程。
- 点击外部、关闭按钮、Escape 或 Android 返回键可关闭面板。关闭面板不会中止已选渠道的准备，换源结束时会提示结果。

## 播放行为

解析新链接和跨平台匹配期间保持原音频及暂停状态。进入实际音频加载前才捕获最新进度与播放意图；按目标音频时长限制恢复位置。支持在准备期间暂停、拖动进度，或继续选择另一个渠道。

新音频准备成功后更新来源、音质、通知栏元数据和歌词请求，保留队列中的原歌曲身份、封面以及歌词页位置。加载或解码失败会重新加载原音频并接续进度；原链接也已失效时显示播放失败，不宣称恢复成功。换歌或停止会取消过期请求，旧请求不能覆盖新歌。

渠道限流、服务端停用和本地冷却仍生效。匹配规则沿用已有录音版本校验：艺人、曲名、版本、专辑、可用时长或 ISRC 等证据。未承诺所有渠道都可播放每首歌曲。

## 实现与验证

- `js/player-source.js`、`css/player-source.css`：顶部按钮、快速菜单、完整面板、键盘及主题适配。
- `js/playback-controller.js`：先准备再提交的换源、失败回退、请求取消、进度及元数据接续。
- `js/playback-router.js`、`js/music-service.js`：只尝试指定渠道的手动路由、严格匹配、独立后续偏好。
- `tests/player-source-switch.test.js`：24 项回归，包含快速连续选择、换歌取消、旧歌词隔离、冷却策略、解码回退、优先渠道、原生 Media3 身份/进度/暂停及失败恢复，以及手动渠道在音质调整中不被脚本或离线副本覆盖。

全量 Python/JavaScript 回归、静态站点构建检查、22 项 Android JVM 测试、Android Lint 和 APK 构建通过。浏览器使用真实 HTML 音频和受控 WAV/接口响应验证完整页面；覆盖 320px 窄屏、横屏、放大字体、深浅主题、歌词页、返回键、外部点击和焦点恢复。脚本：`scripts/verify_android_source_switch.js`（本地服务端口 8794）。
