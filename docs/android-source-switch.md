# Android 播放器换源：C 方案

播放器顶部显示实际音源，例如「GD · 网易云」或当前脚本名称。1.18.4 预览版的就近菜单展示已配置的自定义主用、备用音源，以及当前平台的三个快捷渠道；「全部平台与渠道」打开底部面板。封面页和歌词页共用入口。

## 操作与范围

- 点按渠道即尝试切换当前歌曲；当前渠道带勾选标记，音质使用实际返回结果。
- 完整面板提供「自定义」、网易云、QQ 音乐、Apple Music、酷我和酷狗渠道。内置渠道跨平台先搜索同一录音版本，不直接转用原平台歌曲 ID；无法确认同曲时保留原音源。
- 「后续播放也优先使用」初始不勾选。勾选后在本次切换成功时记住渠道，也可以对已经在播放的渠道设置优先。下次播放优先尝试该渠道，不可用时自动回退。此偏好保存在本机，不更改搜索、发现页的平台筛选；可在完整面板恢复自动选择。
- ChKSz 仅能手动用于当前歌曲，不会成为后续默认或用于预加载。本地、离线音频和 Bilibili 视频显示相应说明。
- 「设置 → 音乐源」继续管理 LX 脚本的 HTTPS 链接，沿用主用、备用两个位置。保存后菜单和后续优先下拉框立即更新，显示脚本 `@name`；旧配置尚未解析名称时显示「导入主音源 / 导入备用音源」。名称与已验证的平台、音质能力保存在本机，重启后可继续显示。
- 自定义音源按当前歌曲及已确认同曲记录中的有效平台 ID 解析。没有有效 ID、脚本不支持当前平台/音质、已关闭或冷却时，选项显示原因。空位置不显示，没有任何配置时提示到设置导入。
- 手动点击主用或备用只尝试该脚本，不暗中切到其他来源；解析、加载或解码失败保留原音源。勾选后续优先时，下一首按选中脚本、另一个脚本、内置渠道的顺序尝试。音质调整优先保持本次手动选择，预加载不执行脚本。显式优先内置渠道时仍走内置路由，恢复自动选择后回到主用、备用、内置的默认顺序。
- 关闭自定义音源或清空当前优先位置时恢复自动选择，并同步设置摘要。导入失败保留旧配置，进行中的换源若发现配置已经变化，会丢弃旧结果；切回内置渠道时清除旧脚本来源标记。
- 点击外部、关闭按钮、Escape 或 Android 返回键可关闭面板。关闭面板不会中止已选渠道的准备，换源结束时会提示结果。

## 播放行为

解析新链接和跨平台匹配期间保持原音频及暂停状态。进入实际音频加载前才捕获最新进度与播放意图；按目标音频时长限制恢复位置。支持在准备期间暂停、拖动进度，或继续选择另一个渠道。

新音频准备成功后更新来源、音质、通知栏元数据和歌词请求，保留队列中的原歌曲身份、封面以及歌词页位置。加载或解码失败会重新加载原音频并接续进度；原链接也已失效时显示播放失败，不宣称恢复成功。换歌或停止会取消过期请求，旧请求不能覆盖新歌。

渠道限流、服务端停用和本地冷却仍生效。匹配规则沿用已有录音版本校验：艺人、曲名、版本、专辑、可用时长或 ISRC 等证据。未承诺所有渠道都可播放每首歌曲。

## 实现与验证

- `js/player-source.js`、`css/player-source.css`：顶部按钮、快速菜单、完整面板、键盘及主题适配。
- `js/playback-controller.js`：先准备再提交的换源、失败回退、请求取消、进度及元数据接续。
- `js/lx-music-sources.js`：导入目录与能力、名称持久化、指定脚本解析、主备优先顺序、配置变更通知。
- `js/playback-router.js`、`js/music-service.js`：指定渠道的手动路由、严格匹配、独立后续偏好，以及内置与自定义来源的衔接。
- `tests/player-source-switch.test.js`、`tests/lx-music-sources.test.js`：37 项回归，覆盖连续选择、换歌取消、旧歌词隔离、冷却、解码回退、原生 Media3 进度/暂停恢复、导入配置变化、主备偏好、有效平台 ID，以及音质调整和切回内置渠道。

全量 104 项 Python、585 项 JavaScript 回归、静态站点构建检查、22 项 Android JVM 测试、Android Lint 和 APK 构建通过。浏览器通过实际设置表单导入受控 LX 脚本，在隔离的 Worker 中解析，并用真实 HTML 音频播放受控 WAV；验证自定义主备选择、下一首优先、失败恢复、关闭/移除联动。另覆盖 320px 窄屏、横屏、放大字体、深浅主题、歌词页、返回键、外部点击和焦点恢复。脚本：`scripts/verify_android_source_switch.js`（本地服务端口 8794）。这些检查验证流程，不代表第三方脚本或所有歌曲均可用。

实装截图：`output/playwright/android-source-custom-menu.png`、`android-source-custom-all.png`、`android-source-custom-settings.png`。截图的歌曲、封面、脚本名和接口为验收样例。
