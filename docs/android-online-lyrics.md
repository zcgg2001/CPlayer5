# Android 在线逐字歌词

1.15.0 Android 预览版在已有歌词与封面缓存改进之上，增加 QQ QRC 与酷狗 KRC 的后台补充。
1.18.5 增加网易云精确 ID 的独立原生通道，修复音乐墙推荐歌曲只依赖音频渠道歌词的问题。
无需更新网站服务端：APK 在固定的 `/android-player/online-lyrics` 路由读取公开歌词，
通过现有歌词渲染器和 Media3 播放时钟显示。普通网页使用同源渠道及 LRCLIB，不调用 Android 原生路由。

## 与原有行为的差异

| 场景 | 原有行为 | 当前 Android 行为 |
| --- | --- | --- |
| 音乐墙网易云歌曲 | GD 空歌词后可能停止 | 原生按精确 ID 独立取 LRC / YRC，同源主渠道空结果时也可继续回退 |
| QQ 歌曲 | 通常只拿到逐行 LRC | 按歌曲 MID / 数字 ID 获取 QRC，保留真实逐字时间与可用翻译、罗马音 |
| 酷狗歌曲 | 下载 LRC | 按歌曲 hash 查询推荐歌词并下载 KRC；接口仅返回 LRC 时如实显示逐行 |
| 普通渠道响应慢 | 等待该渠道歌词 | 补充请求独立运行；任何一路先返回都可以显示 |
| 已有完整逐行歌词 | 逐字版本容易仅凭格式优先 | 新候选至少达到当前同步歌词最长文本的 80%，才参与自动选择 |
| 用户导入歌词 | 使用手动文档 | 后台可以更新在线候选，但继续显示手动文档；点「恢复在线歌词」才切回 |
| 再次播放 / 离线 | 读取原有歌词缓存 | 最近 12 首的在线缓存同时包含已补全的逐字文档、翻译和罗马音 |

网易云保留接口实际返回的 YRC、LRC 与翻译/罗马音。LRCLIB、本地文件和 Bilibili 字幕仍保留各自通路。
没有真实逐字数据时，界面仍标明「逐行同步」。不能把普通 LRC 的字符动画当成逐字时间轴。

## 数据与回退

- 网易云：公开 HTTPS `/api/song/lyric/v1`，空结果或失败再尝试 `/api/song/lyric`；使用原曲数字 ID，与取流音源分离。不要求登录或部署新服务端。
- QQ：先核对 MID 对应的歌曲详情，再调用公开的 `GetPlayLyricInfo`；返回的数字歌曲 ID 必须一致。
- 酷狗：只使用歌曲 hash，不进行歌名模糊搜索。多个歌词候选时采用接口推荐 ID；无法确定则回退原歌词。
- 只识别已知渠道 ID。煎饼来源必须是 `www.jbsou.cn/api.php`，类型与平台一致。
- 上游通过 HTTPS 读取，不跟随重定向，不携带本站 Cookie、令牌或用户凭据。
- 每次原生 HTTP 调用最多 4.5 秒，每次 JavaScript 补充最多 10 秒；响应最多 512 KiB，单个编码层最多 256 KiB，解压后最多 2 MiB。
- 成功补充在会话内保留 5 分钟，失败冷却 30 秒，最多 12 条；主动刷新可绕过该缓存。实际歌词文档另存入现有本机歌词缓存。
- 切歌会取消 JavaScript 请求并校验歌曲代次，旧结果不能覆盖当前歌曲。已发出的原生 HTTP 可能运行至自身超时。
- 手动歌词、每首歌曲的时间校正和外观选择不被异步结果重置。补充失败继续使用原渠道或本机缓存。

QRC 密码格式兼容核心来自 MIT 许可的 `qrc-decoder@1.0.2`，保留其及上游 LyricDecoder
许可，见 [`js/vendor/qrc/README.md`](../js/vendor/qrc/README.md)。使用浏览器原生有界解压，
兼容 QRC 的末块零填充；没有复制 myMusic 的实现。

## 验证

2026-11-25 的公开接口抽样：QQ 样本解析出 63 行、602 个逐字片段；酷狗样本解析出
73 行、526 个逐字片段。只记录格式和数量，不将真实歌曲歌词加入仓库。

自动化使用原创测试文本与固定 QRC 密文，验证解码、原始时间边界、翻译/罗马音、
KRC 偏移、错误身份、取消、大小限制、解压膨胀、完整度选择和失败回退。
Android MockWebServer 测试检查原生实际请求、精确 ID、推荐候选、无凭据和大小限制。

使用项目要求的 Node 26.12.0 运行 `npm test`，然后运行 `npm run build`、
`npm run check:build` 和 `sh scripts/build_android.sh`。
浏览器验收回调是 `scripts/verify_android_online_lyrics.js`，使用 Playwright CLI
在 `http://127.0.0.1:8793` 的 Android 布局中执行；网络响应由原创样本控制。

1.15.0 验收结果：104 项 Python、538 项 JavaScript、22 项 Android JVM 测试通过；
静态检查、网站构建检查、APK 构建与 lint 通过（0 错误，4 项既有警告）。
在线逐字页面的 9 个场景和原歌词缓存的 7 个回归场景全部通过，未出现浏览器未捕获异常。
已逐项核对 APK 中的新歌词模块及许可文件与工作区一致。

1.18.5 的渠道回退、音乐墙选歌、加载状态和重试验收见 [音乐墙歌词修复](android-wall-lyrics.md)。

公开接口可用性受网络、地区及平台变更影响。浏览器验收与 JVM 测试不等同于 Android
真机验收；本轮未安装到设备，也未验证锁屏或通知中的运行效果。
