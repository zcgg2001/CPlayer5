# 跨源曲库与音乐元数据

发现音乐、桌面搜索和手机搜索提供「跨源曲库 · 聚合搜索」。普通列表的「歌曲资料与音源」也可打开资料面板。GD 继续作为默认源；聚合和补充资料均不调用 ChKSz。

## 实体与合并规则

`js/music-catalog.js` 提供歌曲作品 `songEntity`、录音版本 `version`、艺人 `artists`、专辑 `albumEntity`，以及保留渠道原始 ID 的 `sources`。原来的播放字段仍可使用；新加入队列的聚合录音使用 `catalogId`，避免不同平台数字 ID 撞车。

同平台 ID 或一致 ISRC 是强证据。跨平台无 ISRC 时，只有歌名、歌手、版本和专辑一致，且已知时长相差不超过 3 秒，才进行合并。未知歌手、缺失专辑、不同 ISRC、显著时长差异保持分开。括号中的 Live 场次、Remix 制作者、重制版描述不能随意剥掉。Bilibili 视频独立。歌曲客自身 ID 不冒充酷我 ID。

这是保守的录音匹配，不是全网实体知识图谱：跨平台不同拼写可能不能自动合并；名字相同的艺人暂按展示实体处理，平台 ID 保留在 `providerId`，不声称验证过真实身份。合并的元数据保留 `provenance`；界面展示各字段来源，悬停可查看冲突值。

## 搜索与可用性

- 用户主动搜索才查询 GD 和 9 个公开渠道，每页各最多 10 条，并发最多 3；25 秒单源超时。部分渠道失败时仍展示其他结果，支持取消和加载更多，每次搜索最多 10 页。
- 初次结果自动检查前 3 条的首个非受限音源；可检查前 10 首，或在详情里逐个检查所有候选音源。
- `unknown` 待验证；`resolved` 仅获取到了地址；`playable` 已通过 Range 请求读取音频签名。只取前缀并取消流，不下载整首歌曲。
- 明确的上游 `login_required` / `no_copyright` / `region_restricted` 才标注需登录 / 无版权 / 地区限制。超时、403、502、CORS 不能推断版权。
- 可播结果按请求音质缓存 5 分钟；失败 1 分钟。只缓存检查信息，不保存签名音频地址。状态会过期且不构成持续可播保证。
- 聚合播放优先已验证音源；解析失败尝试其他未受限音源。指定「用此音源播放」时只使用该音源。音频加载阶段的失败仍由原播放器处理，不自动跨源跳过媒体播放错误。歌词使用实际播放源的 ID。

## 元数据与内容

搜索适配器保留时长、出版时间、艺人和专辑信息。打开资料面板时，含网易云 ID 的录音按需请求 `/api/v1/music/metadata?source=netease&id=...`，查询固定网易云公开接口，补充封面、头像、厂牌、发行日期及可获得的介绍。数字 ID 验证、请求超时、单次上游 512 KiB、成功结果 5 分钟缓存、最多 60 个缓存项限制资源占用。专辑和艺人接口失败不丢弃基础歌曲资料。

资料模型接受时长、码率、发行日期、语言、风格、厂牌和 ISRC，但公开音源不保证提供这些字段。没有资料时显示「未提供」；不根据歌名猜语言或风格。实际码率 / 格式显示在音源检查结果中，与资料标称码率分开。

已知且无签名的网易云 / QQ 图片 CDN 提供多个尺寸链接；其他代理或签名地址原样保留，不保证未知地址存在高清版本。头像只有上游提供实际图片时显示。

相似歌曲基于当前搜索结果的歌手、专辑或风格交集；相似艺人仅基于已知共同风格，均显示理由。数据不足时明确提示，不随机凑推荐。

## 验证

`tests/music-catalog.test.js` 覆盖误合并防护、多版本、跨源 ID、元数据来源、图片地址、音频签名预检、过期、并发、取消、来源回退和歌词 ID。`tests/music-metadata.test.js` 覆盖接口验证、部分失败、响应上限和补全不增加虚假音源。`tests/cloudflare-runtime.js` 在 workerd 中验证新资料接口及并发请求。
