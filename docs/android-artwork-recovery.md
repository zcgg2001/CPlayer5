# Android 缺封面补全

2026-11-25，继歌词与共用封面缓存之后的第二阶段。参考 myMusic `38a263531e2828e3007789a127effb3bfd398910` 的公开目录补图思路，结合 ZPlayer 的专辑发行身份、WebView 和 Media3 独立实现。

## 使用方式

正常封面继续使用原图、缩略图/原图回退和原平台精确 ID 查询。仅当前播放器在这些路径失败后尝试 iTunes 搜索；音频与歌词独立运行，列表和相邻封面不会发起此类自动搜索。Bilibili 和本地文件不自动使用音乐目录替换封面。

「设置 → 播放页封面」提供自动匹配开关。「更换当前歌曲封面」可展示候选、选择其他专辑封面和恢复原图。所有候选都要求歌名、歌手和版本吻合；不同专辑须由用户主动选用。恢复原图后，这首歌不再自动补图。按钮在未选歌时禁用，切歌会取消旧页面操作。

自动采用还要求专辑一致且只存在一个匹配的专辑结果；双方提供时长时差值不得超过 3 秒。Live、Remix、翻唱不按基础歌名合并。信息不够或匹配不唯一时继续显示占位图，可手动查询候选。

## 数据与缓存

- APK 通过固定的原生公开查询入口访问 `itunes.apple.com/search`，使用香港区目录；不依赖本站后端部署，不携带站点 Cookie 或 Authorization。浏览器的 Android 布局预览直接查询同一个公开 API。
- 查询内容为歌名和歌手，结果上限 30 条；请求有超时，JSON 不超过 512 KiB，不跟随原生接口重定向。前端只接受 iTunes 的公开 `mzstatic.com` 封面。
- 同歌名/歌手的查询共享在途请求，成功结果保留 5 分钟，最多 100 份。网络错误不作为永久缺图记录；自动重试有 30 秒冷却。
- 最多保存 100 份封面选择。键包含原始歌曲身份与发行资料的指纹，避免切换音源或同名歌曲串图。只保存公开图片引用；图片字节复用 Android 的 64 MiB 缓存。
- 手动选择和恢复原图优先于在途自动查询。即使本机存储写入失败，本次会话的选择也保留，并显示保存状态。
- 简繁匹配使用本地 `opencc-js@1.4.2` 的 t2cn ESM 资源，首次匹配时初始化；不修改可见歌名或歌词。代码为 MIT，词典为 Apache-2.0，许可文件与资源一起打包，见 `js/vendor/opencc/`。

## 检查与复跑

最终验证：使用项目规定的 Node.js 26.12.0，104 项 Python、531 项 JavaScript 测试及静态检查通过；17 项 Android JVM 测试、Lint（0 错误、4 项提示）与 APK 构建通过。网页构建及产物检查通过，第一阶段歌词页面回归也通过。缺封面页面验收在 390×844 视口完成，并检查 320 像素窄屏无横向溢出。

新增 Node 测试 `tests/artwork-recovery.test.js` 覆盖匹配、简繁、跨音源身份、同名不同发行、共享查询、取消、失败重试、体积限制、手动选择/恢复与自动查询竞争、持久化及列表不自动搜索。

新增 JVM 测试 `ArtworkSearchHandlerTest` 验证固定目标与查询参数、无凭据请求、拒绝未知入口、控制字符、重定向、超大响应和 HTML 错误页。

页面回调 `scripts/verify_android_artwork_recovery.js` 使用实际 Android 布局、原创测试歌词、静音音频和本地生成的封面色块，隔离外部请求。验证自动补图不阻塞播放、不同版本过滤、手动更换后各播放器表面同步、重载后恢复选择、恢复原图、正常封面不额外查询、自动开关和窄屏布局。

同时修复设置页关闭后 300 毫秒内重开仍被旧延时隐藏的问题，避免快速操作时入口消失。

```sh
python3 -m http.server 8793 --bind 127.0.0.1
# 在另一个终端执行，也可使用本机 Playwright skill 的 CLI wrapper。
playwright-cli -s=android-artwork open http://127.0.0.1:8793/offline.html
playwright-cli -s=android-artwork run-code --filename scripts/verify_android_artwork_recovery.js
playwright-cli -s=android-artwork close
```

本次公开接口抽查中，中国区对两首样本均返回空结果，香港区返回《有何不可》的《自定義》发行资料；前端将「許嵩 / 自定義」与「许嵩 / 自定义」正确匹配。这是单个公开样本的可用性检查，不代表全部曲目、地区或设备的命中率。

Android 真机的系统通知、锁屏及厂商后台限制仍需要实机验收。使用者可以在匹配不符时手动更换或恢复原封面。
