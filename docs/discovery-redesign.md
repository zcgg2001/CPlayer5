# 发现音乐页优化

在现有原生 JavaScript 播放器中接入真实搜索、播放和队列，复用现有音源接口与歌词效果，不引入独立的 React 演示页面或虚构歌曲数据。

## 界面和行为

- 页头压缩到 28px 标题与一行说明，内容最大宽度 1280px。侧栏正常宽 240px，768–1199px 收起为 72px 图标栏。
- 音源选择分为平台与渠道两级；所有选择入口同步，支持键盘选择及溢出滚动。GD 仍为默认音源，页面不依赖 ChKSz 额度。
- 60px 歌曲行增加时长、播放状态、收藏和更多菜单；专辑列不超过 320px，在窄屏隐藏。封面保留签名查询参数，加载失败显示渐变音符。
- 支持结果内筛选、按歌曲/歌手/时长排序、播放全部、批量加入队列、收藏筛选和加载更多。收藏保存在本浏览器 `cp_favorites_v1`，不进行账号同步。
- 更多菜单的「复制歌曲链接」生成带渠道与关键词的搜索分享地址。下载入口沿用各渠道现有能力限制。
- 桌面底栏为 88px 三段式，含歌词、收藏、模式和队列数量；手机搜索与发现面板内提供迷你播放条。动漫进度条皮肤默认关闭，可在设置中开启。
- 加载显示骨架，失败显示重试；ChKSz 失败仍有切换 GD 的按钮。保留上次成功结果时显示其更新时间。

## 数据边界

列表时长来自音源提供的秒数，网易云 `dt` 转为秒，QQ 使用 `interval`。未返回时长时显示 `—`，当前播放行在音频元数据就绪后更新。不会虚构歌曲时长、版权状态或音质。第三方源的可用性和最终音质仍取决于上游。

## 验证记录（2026-11-07）

- 1440×900：首屏完整展示 7 首，页头加筛选区域约 180px，播放器 88px。
- 1024、768、390px：无文档横向溢出；窄屏专辑列隐藏，平台和渠道仍可切换。
- 实际网易云歌曲播放成功，时长 3:30；暂停、快进 5 秒、歌词开关、Escape 返回焦点和 `/` 搜索可用。
- 实际搜索结果从 10 首加载至 20 首；收藏在刷新后保留；筛选、空态重置、更多菜单和单独加入队列可用。
- 浏览器注入一次 502 响应验证骨架与错误提示，解除注入后点击重试恢复 10 首真实结果；测试响应不包含在产品代码中。
- 手机迷你条已验证播放/暂停、返回完整播放器，以及在搜索面板与发现面板间复用；未发现页面脚本错误。
- 104 项 Python、253 项 JavaScript、6 项 Worker 运行时测试通过，静态资源检查与 Cloudflare 构建/部署预检通过。
