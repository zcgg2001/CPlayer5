# 发现与推荐

首页提供每日推荐（最多 30 首）、私人电台、继续播放、猜你喜欢、新歌速递、通勤 / 学习 / 深夜 / 跑步歌单，以及榜单与标签检索入口。手机端在音乐发现中新增「推荐」页签，复用同一份状态，切换屏幕尺寸不重新请求或丢失电台会话。

## 数据与推荐

- 新的 `/api/v1/discovery/charts|playlist|playlists|artist` 接口只读取网易云公开目录，不使用登录 Cookie、密钥或 ChKSz 额度。歌曲播放使用 GD 候选源，解析与歌词继续沿用现有播放器。
- 首屏并行请求热歌榜与新歌榜。单个接口失败保留其他结果，全部失败可使用一天内保存的候选；显示重试和数据状态。
- 推荐在浏览器内计算，依据实际听歌记录（累计至少 15 秒）、收藏、导入库中的艺人、已知语种 / 年代 / 风格以及偏好主题歌单。每天按北京时间和本机固定种子排序，控制同一艺人连续占据推荐位置。当天上游曲库变化、更新偏好、反馈会改变结果。
- 每日推荐有足够候选时展示 30 首；候选不足显示实际数量，不生成虚构歌曲。新歌速递保留网易云新歌榜顺序，不把关键词搜索结果标为新发行。
- 场景标签属于歌单上下文，不会写成每一首歌的风格、BPM 或语言元数据。City Pop、后摇、80/90/00 年代使用公开歌单搜索；其他分类使用公开歌单目录。
- 榜单目录覆盖综合、上升、新歌、风格、地区和全部；分类只按返回的榜单名称，排名仍是上游原始顺序。旧榜单页同样改用公开接口。
- 歌曲可用性仍遵循统一曲库模型，未经音频验证显示「待验证」。网易云歌曲的收费标记不能证明 GD 的可用性，不据此宣称可播或无版权。

## 电台与继续播放

私人电台从推荐候选开始，继续按听歌艺人或偏好主题取曲。歌曲电台依据已知的同艺人 / 风格关系扩展，艺人电台只保留匹配艺人的候选。它们是本地规则推荐，不是上游账号的私人 FM，也不宣称音频相似度分析。

电台同时支持播放结束自动续播、下一首、退出。会话内去重，排除“不感兴趣”记录；过期请求取消后不能启动旧歌曲。每次补充最多请求三批，空列表或失败显示可重试状态；每会话最多 100 批 / 500 首，达到上限可重新开启。音源解析或音频播放失败不会无限自动重试，用户可点击下一首。手动选择普通歌曲或上一首时退出电台，退出后保持当前音频与原队列。

播放进度每约 10 秒及暂停 / 页面隐藏时保存；继续播放在新音频就绪后恢复位置，播放完毕的歌曲从头开始。不会自动恢复播放或后台上传历史。

## 冷启动、标签与反馈

「音乐偏好」可选最多 12 个标签。每日从中轮换两类主题扩充候选，所有选择仍参与已有元数据评分。无历史时从公开榜单探索。

支持网易云公开歌单 ID / 链接、本地 JSON 歌单（2 MB、1,000 首上限）、当前队列与收藏分析。导入先显示数量和常见艺人，用户点击后才加入推荐库，保留播放队列。上游只返回部分曲目时明确显示已取得 / 总数，不绕过私密歌单或登录限制。本地分析针对已有歌曲元数据，不读取音频文件内容。

JSON 支持数组、`tracks`、`songs` 或 `playlist.tracks`；保留已有平台 ID 与 provider。示例：

```json
{"tracks":[{"id":"123","provider":"gd","name":"歌曲名","artist":"艺人名","album":"专辑名","metadata":{"duration":210,"language":"国语","releaseDate":"1995-01-01","genres":["City Pop"],"bpm":110}}]}
```

标签精确筛选支持语种、80s / 90s / 00s、风格、BPM 和时长（秒）。多个条件取交集，缺字段不匹配；BPM 常依赖导入数据，公开曲库通常不提供。主题检索和精确元数据筛选在界面中分开说明。

“不感兴趣”立即移除推荐并用于后续电台，可撤销或在偏好中重置。上限 500 条；历史最多 100 首，导入库最多 1,000 首。存储位于当前浏览器 `cp_discovery_profile_v1` 和 `cp_recommendation_pool_v1`，不跨设备同步，不保存音频直链。存储不可用时使用本次会话状态并提示。

## 接口边界与验证

公开接口固定目标域名，校验数字 ID、分类长度与分页范围；不跟随跳转，12 秒超时、2 MiB 响应上限。只缓存已完成的公开 JSON，5 分钟 / 24 条，不在 Worker 请求之间保存待完成 I/O。

自动测试覆盖规则排序、去重与反馈、真实元数据筛选、导入校验、持久化与敏感字段投影、电台取消 / 去重 / 有界重试、公开接口响应边界和 workerd 并发。浏览器验证包括每日 30 首、GD 实际播放、电台续播、42 秒恢复、导入预览、反馈撤销和移动端原生弹窗。
