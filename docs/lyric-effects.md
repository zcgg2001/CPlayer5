# 歌词效果

在「播放器设置 → 歌词设置 → 歌词效果」选择，共 **20 种效果**，另有随机模式。设置预览、桌面播放器和手机播放器共用渲染器；字号支持 12–60 px，偏好自动保存在当前浏览器，可恢复为 AMLL / 36 px。

## 参考与适配范围

设计参考 [chthollyphile/folia-major](https://github.com/chthollyphile/folia-major)，完整模式清单核对版本为 `50a3e5239922a32ca0d55cbfa1cdcea9cdfe0278`：

- [17 种内置模式的类型定义](https://github.com/chthollyphile/folia-major/blob/50a3e5239922a32ca0d55cbfa1cdcea9cdfe0278/src/types/visualizerModes.ts)
- [各模式的原始实现](https://github.com/chthollyphile/folia-major/tree/50a3e5239922a32ca0d55cbfa1cdcea9cdfe0278/src/components/visualizer)

这里按各模式的视觉特征独立实现 DOM、SVG 和 CSS 适配版，没有移植或复制 Folia 的 React、Canvas、Three.js 和 Framer Motion 渲染代码。**完整覆盖模式清单不代表完整复现原项目的渲染引擎、3D 场景、音频能量分析、逐字时间轴或全部场景参数。**

歌词使用真实 LRC 行级时间戳，入场动画由换句触发。文字拆分仅用于排版，不表示真实逐字演唱时间；翻译歌词、点击和键盘跳转继续使用原有播放逻辑。流光和云阶保留原有本地 ID `glow` / `cloud`，并兼容 Folia 的 `classic` / `partita`，已有偏好不会失效。

## 动效与可读性

- 仅当前句生成场景；换句、切换效果、重新加载歌词时清理旧场景，调整字号时重新排版。
- 隐藏的播放区域、暂停播放和停止预览时暂停动画；系统开启「减少动态效果」后保留静态排版。
- 长歌词自动换行，极长字幕跳过复杂拆分；装饰与邻句回声不重复加入朗读文本。
- 场景采用有限数量的 SVG 元素和 CSS 动画，无额外逐帧 JavaScript 循环；新模块和样式包含在 PWA 离线缓存中。

## 实现位置

- `js/lyric-catalog.js`：唯一模式清单、别名和随机选择。
- `js/lyric-effects.js`：设置、保存、预览和歌词生命周期。
- `js/lyric-composition.js`：心象与倾诉的文字排版。
- `js/lyric-scenes.js`：13 种场景渲染及清理。
- `css/lyric-effects.css` / `css/lyric-scenes.css`：效果、响应式布局及减少动态效果支持。

验证包含模式覆盖、偏好兼容、随机不重复、离线资源与现有播放逻辑的自动化测试；实际浏览器检查覆盖设置预览、桌面和手机歌词、换句及跳转。
