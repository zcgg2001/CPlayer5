# 歌词效果

在「播放器设置 → 歌词设置」或桌面沉浸页的「歌词外观」中调整。20 种模式、六类背景与设置预览共用 `js/lyrics/` 运行模块；原有模式 ID、随机偏好和 12–60 px 字号保持兼容。

## 同步与格式

播放器直接读取 `audio.currentTime`。YRC、增强 LRC、TTML、文本 QRC、KRC 中有效的词级时间用于逐字填色；普通 LRC/VTT 只按句同步，不凭文字长度伪造演唱时间。缺少时间戳的文本可滚动阅读，空歌词显示明确状态。

- 在线歌词优先使用接口提供的丰富格式，同时保留翻译、罗马音和 TTML 和声/角色信息。
- 可导入 LRC、YRC、TTML、VTT、文本 QRC、文本或 `krc1` 压缩 KRC、TXT。单文件最多 2 MB、5000 行。
- TTML 支持常用 begin/end/dur、嵌套秒数偏移、逐词 span、换行、翻译、罗马音与 `x-bg` 和声；没有实现完整 TTML 排版、帧时间制或顺序容器规范。
- 加密 QRC 需要先转换为文本格式；KRC 解压依赖浏览器的 `DecompressionStream`。
- 「歌词校正」正值让歌词提前，按歌曲保存；「提前入场」只影响出现时机，逐字填色仍以真实词时间为准。点击歌词会反向扣除校正值后跳转。

## 背景融合与音乐喷泉

歌词区域不再有独立玻璃底板、边框和阴影。背景光晕/图片以柔和遮罩融入播放器的专辑氛围；手机端歌词按钮也排除了旧的玻璃按钮样式。

「显示与背景」提供通用光晕、隐现像素、莫奈封面、漫游纸感、空/星空、HTTPS 嵌入网页六类背景，可调主题色、透明度、模糊、自定义图片。嵌入网页使用受限 iframe，网站自身若禁止嵌入则不能显示。

底部音乐喷泉默认开启，复用播放器已有 analyser，不重复连接音频源。48 条桌面水柱、24 条手机/省电水柱由实际频谱驱动，附带少量水滴；透明且不接收点击。可以关闭或调整强度。暂停、无频谱输入、切离歌词视图、系统减少动态效果或静止模式下不显示喷泉。它提供频谱反馈，不是拍点/鼓点检测。

## 来源与偏好

手动导入的歌词优先保留；刷新在线候选不会覆盖手动选择。可恢复在线歌词，或在当前歌曲已经关联、版本匹配的候选中比较完整度。「寻找更完整歌词」不搜索任意同名歌曲，也不能保证上游一定提供逐字数据。

全局外观使用 `cp_lyricStudio_v1`，旧效果/字号继续使用 `cp_lyricAppearance`。最近 12 首歌的手动歌词、时间校正、可选单曲外观保存在 `cp_lyricTracks_v1`。配置支持 JSON 导入/导出；时间校正不随外观导出，避免套用到另一首歌。浏览器存储不足时保留本次应用结果并提示。

## 运行与参考

普通、AMLL、跃音默认列表视图，其余默认舞台；也可手动切换。列表继续复用原有的浏览、跟随和返回当前句行为。每个可见主视图由同一个媒体时钟更新，暂停、缓冲和不可见时停止持续帧循环；背景 Canvas 按需加载，限制 DPR 和粒子数。设置预览使用同一渲染器与原创示例时间轴。

按 [Folia](https://github.com/chthollyphile/folia-major) 的功能和视觉特征独立实现，未复制上游渲染代码或素材。源代码参考固定于 `867dc31aa537482f6b8bbec0bb1665a422e78ef4`；此次未运行上游应用做逐模式同素材视觉验收，因此不能将模式清单覆盖理解为原版功能/视觉完全一致。

实现入口：`js/lyric-effects.js` → `js/lyrics/controller.js`；数据、时钟、来源、背景和渲染器分别在 `js/lyrics/` 下。旧场景文件保留兼容测试，不再驱动新的主歌词舞台。验证记录见 [实施与验收记录](lyrics-validation.md)。
