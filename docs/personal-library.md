# 个人库

桌面侧栏、手机顶部红心以及设置中的“我的音乐”进入个人库。现有歌曲红心和设置页保存的歌单继续可用。

## 使用

| 功能 | 操作与行为 |
| --- | --- |
| 四类收藏 | 歌曲、专辑、歌手、歌单分别筛选。歌曲更多菜单可保存到歌单、收藏专辑/歌手；公开详情也提供收藏按钮。缺少平台 ID 的专辑/歌手以名称收藏，查看时使用搜索。 |
| 自建歌单 | 新建、保存当前队列、编辑名称/描述/HTTPS 封面、移动歌单和曲目、按名称/歌手排序。重复歌曲自动合并，默认仅自己可见。 |
| 协作与公开 | 登录后从歌单开启云端协作。创建者邀请已有用户名，接收者在“歌单”中接受。编辑者可修改曲目，查看者只读；只有创建者能管理成员、删除、公开或恢复私密。公开链接可在选择登录或游客后查看。邀请仅保存在站内，不发送邮件/短信。 |
| 自动歌单 | “我喜欢”由歌曲红心生成；“最近播放”保留最近 200 次实际收听记录，支持重新播放。 |
| 听歌报告 | 每年收听分钟、播放次数、活跃天数、逐月时长、最常听的歌手；可导出报告 JSON。按 UTC 日期聚合，保留当前及此前 23 个月。启用后的实际播放才计时，暂停、缓冲、拖动不计。 |
| 标签与笔记 | 每首歌最多 12 个标签、0–5 星、2,000 字符笔记，与账号同步。 |
| 离线 | 歌单可尝试保存提供下载的曲目，也可导入已有 MP3/FLAC/M4A/AAC/OGG/WAV/Opus。缓存命中时优先使用本机音频，显示“离线”，支持删除单曲、清空和容量调整。 |
| 导入迁移 | 公开网易云/QQ 歌单完整链接、JSON、CSV、M3U 均先预览再导入。JSON 完整备份含收藏、私有歌单及可访问的协作歌单快照、笔记、历史与统计；导入冲突歌单保存为私密副本。 |

## 边界与数据归属

- 云同步使用已有逐项三方合并与版本校验。多人同时修改云端歌单会提示版本冲突并保留编辑，不静默覆盖。协作需要联网，不提供实时同屏编辑。
- 断网启动时，曾登录且仍保留身份的设备可明确选择“离线打开…的本机资料”。只能播放已缓存音频；该入口不签发服务器会话、不赋予云端权限，恢复联网后验证当前身份才同步。退出登录会隐藏该账号的离线入口，游客空间独立。
- 离线文件存入 IndexedDB，按账号隔离；它们不进入云同步或 JSON 导出。换设备后，本地音频需重新导入。默认每个账号 512 MB，可设 64–2048 MB，每首最大 64 MB，浏览器实际存储额度仍可能更小。
- 保存远程音频只使用现有明确允许下载的来源；GD、QQ 等仅在线播放来源会说明无法下载。只保存完整可读音频，不把临时播放链接当作离线文件。浏览器清理站点数据会移除缓存。
- 云资料总限额沿用 2 MB / 2,500 项；单个歌单最多 1,000 首，云端协作最多 100 张自有歌单、每张 20 位协作者。收听数据按设备分月累计，避免不同设备覆盖同一计数。完整快照中的过期历史/统计删除项会压缩；旧设备通过三方合并接受删除。
- 网易云导入受现有上游最多 200 首限制，QQ 最多 1,000 首；预览明确标记上游返回不完整。私密、失效、风控链接不保证可导入。短链接需要先打开并复制完整地址。
- CSV 含曲目 ID、名称、歌手、专辑及来源，导出会处理公式前缀。M3U 含 CPlayer 元数据和原平台页面链接，可重新导入 CPlayer；它不是包含直连音频的通用播放器歌单，也不包含音频本身。
- 注销账号会删除服务器私有资料、自有协作歌单及成员关系，并清理当前设备对应的离线文件和推荐记录。其他已离线设备中的文件无法由服务器远程擦除，需要在该设备清理站点数据。

## 服务与部署

Node 启动时沿用现有自动迁移。Cloudflare 发布前先向现有 D1 应用 `migrations/0005_personal_library.sql`，再发布前后端一起构建的版本；迁移只新增歌单和成员表及索引，保留已有账号和音乐数据。当前功能不要求新增第三方服务或密钥。

主要接口：

- `/api/library/playlists`：自己的及已接受邀请的协作歌单，创建私密歌单。
- `/api/library/playlists/:id`：读取、按 revision 编辑或删除。
- `/api/library/playlists/:id/members`：创建者查看、邀请、调整和移除成员。
- `/api/library/playlists/:id/invitation`：接受或拒绝自己的邀请。
- `/api/library/public/:id`：只读取已公开歌单，返回内容不含账号 ID 或成员信息，撤回公开后立即拒绝。
- `/api/v1/library/import?url=…`：校验分享平台与数字 ID 后访问固定上游，禁止任意 URL 转发。

接口复用既有服务端认证、CSRF、限流、内容过滤与响应大小限制。Electron 只向已允许的私有歌单路由发送设备令牌。新 Service Worker 会更新个人库模块；部署后旧标签页应刷新，以使用新的同步数据类型。

## 验证

使用 Node 26 运行：

```sh
npm test
npm run build
npm run check:build
npm run smoke:server
npm run test:worker
npm run cf:check
```

`tests/personal-library.test.js` 覆盖收藏、歌单、迁移、计时、长期同步删减、协作权限/CAS/注销、导入链接约束、音频大小限制和账号隔离。`tests/cloudflare-runtime.js` 在真实 workerd/D1 运行时验证协作接口。

本地浏览器验收使用独立测试账号和合成音频：编辑顺序/描述、标签评分、CSV 导出回导、QQ 链接预览、音频导入/播放/刷新后保留、桌面及 390px 手机布局。停止本地服务器后，已验证缓存外壳启动、明确选择本机账号资料、继续播放离线音频。QQ 固定接口已对一份公开歌单实测返回有效曲目；此结果不保证所有歌单始终可用。

本次验证结果：104 项 Python 测试、419 项 JavaScript 测试、14 项 workerd/D1 测试通过；静态检查、构建检查、Node 服务冒烟和 Cloudflare 发布预检通过。这是功能开发时的本地验收记录；v1.8.0 的正式迁移、发布与线上验证结果见 [Release](https://github.com/zcgg2001/CPlayer5/releases/tag/v1.8.0)。
