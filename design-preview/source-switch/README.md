# Android 播放器音源切换参考稿

三个方案均基于现有 Android 播放器的 Material 配色、专辑旋转木马和底部控制区。`index.html` 是独立设计原型，点击入口、选择渠道和勾选后续优先都只是演示。

| 方案 | 入口与展开 | 使用倾向 |
| --- | --- | --- |
| A（推荐） | 歌曲信息下的「GD · 网易云」胶囊，与音质并排；点击打开底部面板 | 默认方案。来源清楚可见，选择当前歌曲与后续默认的范围明确 |
| B | 进度条上方的「换源」按钮；展开两个常用渠道与「更多」 | 经常换源。单手容易触达，快捷切换不遮住封面 |
| C | 顶部「GD · 网易云」标题按钮；点击展开就近菜单 | 偶尔换源。保持封面和播放区简洁，顶部入口触达较远 |

建议共同采用的行为：

- 默认仅切换当前歌曲；完整面板提供「后续播放也优先使用」，初始不勾选。
- 同平台先展示对应歌曲的渠道；其他平台要确认同曲版本与时长，匹配不确定时供用户选择，不能把原平台 ID 直接传给另一平台。
- 选择新源时展示准备状态；新音频可播放后按可支持的进度接续。切换失败保留原源、原歌曲与进度，并给重试入口。
- 按实际播放结果更新来源和音质；不预先标注「可用」「无损」或虚构测速。
- 歌词页可复用所选方案的音源入口；不把「切换音源」与「切换歌词来源」混为一个操作。

本稿仅展示部分平台与渠道，名称来自当前项目。正式选项应复用现有来源配置与歌曲匹配能力。歌曲、封面及 01:24 进度均为原创示意，未连接播放 API。

浏览器已检查三种入口的展开、选择、默认范围、更多菜单、深浅主题和手机宽度下的参考页。图稿使用 390 × 844 手机画布；这不是正式功能或真机验收。
